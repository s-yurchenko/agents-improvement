# Инструкции для агентов

Состав и формулировки подтверждены пользователем 21 ноября 2026 года. Для подключения в Codex и Claude Code реализован [плагин «Инструкции агента»](../plugins/agent-instructions/README.md); там указаны команды установки и статус проверок.

| Файл | Состав | Применение |
| --- | --- | --- |
| [base.md](base.md) | Десять базовых правил, порядок работы и обновлений в едином списке | Общая основа |
| [optional/graphify.md](optional/graphify.md) | Изучение реализации и работа с графом зависимостей | Дополнение к основе для проектов, в которых выбран Graphify |

Базовые инструкции имеют последовательную нумерацию и одинаковый статус. В пункте о структуре ответа сохранена вся подтверждённая формулировка, включая пояснение в скобках.

22 ноября в раздел «Порядок работы» добавлено согласованное указание использовать готовый скилл `grilling` для существенных неизвестных о цели, требованиях и архитектурных решениях. Перед использованием агент проверяет его доступность; при отсутствии или недоступности предлагает установку либо подключение и выполняет их только после явного подтверждения инженера. Копия скилла в этом репозитории не хранится. Вопросы могут задаваться группами и не ограничены по длине.

Формулировки в этих двух файлах — утверждённые подключаемые тексты. [Запись сверки](../docs/prompts/system-prompts-review.md) фиксирует состав и результат проверки. При изменении правил сначала согласуется точная новая формулировка.

Плагин передаёт общую основу и только выбранные для проекта дополнения, без редакторских пояснений из записи сверки. Обновления берутся из опубликованных коммитов перед новым чатом; продолжение использует прежний снимок. Дословная передача основы в новый чат Codex подтверждена; следующие шаги описаны в [плане развития](../docs/plans/2026-11-21-agents-improvement-roadmap.md).
