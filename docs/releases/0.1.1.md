# Версия 0.1.1 — использование готового скилла grilling

Дата: 22 ноября 2026 года. Основная ветка — `master`, тег — `v0.1.1`.

## Изменения

- Для существенных неизвестных о цели, требованиях и архитектуре базовые инструкции явно направляют агента к готовому скиллу `grilling`.
- Указан источник установки: [mattpocock/skills, каталог skills/productivity/grilling](https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling).
- Перед использованием агент проверяет доступность скилла. Установку или подключение выполняет только после явного подтверждения инженера, затем повторно проверяет доступность.
- Вопросы могут задаваться группами, без ограничения длины. Текст внешнего скилла не копируется и не меняется.
- Версии манифестов Codex, Claude и каталога Claude согласованы: 0.1.1.

Остальные формулировки основы и дополнение Graphify сохранены дословно. Код загрузчика и конфигурации хуков не изменены.

## Получение обновления

Для уже установленного плагина, включая 0.1.0, достаточно нового чата: загрузчик получает актуальную основу из `master`. Продолжение существующего чата сохраняет прежний снимок. Переустановка плагина для получения этих правил не требуется.

Graphify остаётся дополнением на выбор для конкретного проекта. Скилл `grilling` устанавливается отдельно с подтверждением инженера; загрузчик сам его не устанавливает.

## Проверки

- `npm run check`: манифесты, пути и конфигурации обоих клиентов.
- `npm test`: девять тестов загрузчика, включая дословную передачу обновлённой основы в адаптеры Codex и Claude.
- `claude plugin validate`: манифест плагина и каталог Claude.
- Проверка дословной сохранности предыдущих правил и Graphify, совпадения дополнения с планом и локальных ссылок документации.

## Оставшиеся проверки

- Выбор `grilling` и проведение интервью в новом реальном чате после обновления правил.
- Запрос подтверждения, установка и повторная проверка в окружении без скилла; поведение при отказе инженера.
- Реальная сессия Claude Code. Проверки манифестов и адаптера не заменяют эту проверку.
