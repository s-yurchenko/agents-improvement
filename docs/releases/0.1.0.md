# Версия 0.1.0 — первый выпуск

Дата: 22 ноября 2026 года. Основная ветка — `master`.

## Состав

- Утверждённые базовые инструкции и отдельное дополнение Graphify с сохранением дословных формулировок.
- Плагин `agent-instructions` и каталоги установки для Codex и Claude Code.
- Получение правил из GitHub перед новым чатом, полный снимок для продолжения и сохранённая версия с предупреждением при недоступности источника.
- Настройки источника, ветки и дополнений; описание подключения и обновления.
- Русскоязычные инструкции репозитория, документация, отображаемые названия, комментарии к коду и названия тестов. Команды, технические идентификаторы и точные названия элементов сторонних интерфейсов сохранены.

## Проверки

- `npm run check`: манифесты, пути и конфигурации хуков обоих клиентов.
- `npm test`: девять сценариев загрузки, обновления, продолжения, ошибок и сохранности текста.
- `claude plugin validate`: манифест плагина и каталог Claude.
- Локальная установка в Codex и обнаружение синхронного `SessionStart` без ошибок.
- После публикации: установка из GitHub и дословная передача всех 12 разделов `prompts/base.md` в новый чат Codex. Совпадение проверено по снимку и сообщению хука в журнале чата.

## Ограничения

- Перед запуском в Codex необходимо штатно подтвердить доверие к хуку. В проверенной установке пользователь подтвердил доверие, передача базовых инструкций в настоящий чат прошла проверку.
- Поддержка Claude проверена на уровне манифестов и загрузчика; реальная сессия остаётся отдельной проверкой.
- Для работы нужны Node.js 20.11+ и Git. Код плагина обновляется отдельно от Markdown-инструкций.
- Пользу правил ещё предстоит проверить на небольшой реальной задаче.
