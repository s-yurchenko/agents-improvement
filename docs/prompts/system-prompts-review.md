# Системные промпты: подтверждённый состав

Дата подтверждения: 21 ноября 2026 года. Статус: состав и формулировки утверждены пользователем. 22 ноября реализован плагин подключения для Codex и Claude Code; автоматические проверки дословной передачи обоих файлов пройдены. Тексты правил при реализации плагина не менялись.

| Файл | Содержание | Применение |

Полные тексты хранятся в указанных файлах. Этот документ фиксирует состав и результат сверки.

## Результат сверки

- Базовые инструкции собраны в единый список из двенадцати последовательно пронумерованных разделов.
- Оспаривание решений, структура ответа и самостоятельное выполнение работы входят в общий список правил с тем же статусом, что и остальные пункты.
- Тексты базовых инструкций сохранены дословно. Изменены заголовки, группировка и нумерация.
- В правиле о структуре ответа сохранено подтверждённое пояснение в скобках.
- В отдельном варианте с Graphify последовательно пронумерованы два правила и обновлён номер внутренней ссылки между ними. Остальные формулировки сохранены.
- Graphify выбирается для конкретного проекта и не включается в общую основу автоматически.
