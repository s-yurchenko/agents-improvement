# Плагин подключения инструкций

Статус: реализация согласована пользователем и выполнена 22 ноября 2026 года. Первый проверяемый клиент — Codex Desktop; совместимость с Claude Code входит в упаковку и контракт загрузчика. Автоматические тесты пройдены, плагин установлен локально в Codex. Полный запуск ожидает штатного доверия к хуку.

## Результат

Плагин `agent-instructions` устанавливается из каталога плагинов этого репозитория. Синхронный `SessionStart` получает опубликованный текст из `master`, передаёт его целиком в контекст и закрепляет версию за чатом. Продолжение и сжатие контекста используют тот же снимок. Новый чат получает новую опубликованную версию.

## Реализация

- Общий загрузчик на Node.js 20.11+ без внешних библиотек. Git используется только для получения данных из репозитория; обновление исполняемого кода загрузчика происходит отдельно через обновление плагина.
- Раздельные манифесты и конфигурации хуков Codex и Claude внутри `plugins/agent-instructions/`. Основной каталог плагинов — `.agents/plugins/marketplace.json`; совместимый каталог Claude — `.claude-plugin/marketplace.json`.
- Основной текст — `prompts/base.md`. Настройка проекта `.agents/instructions.json` позволяет выбрать `optional: ["graphify"]`; по умолчанию дополнения не подключаются.
- Адрес источника и ветка задаются пользовательским `config.json` в каталоге данных плагина. По умолчанию используется HTTPS-адрес этого репозитория и ветка `master`. Для воспроизводимых проверок допускается абсолютный путь к локальному Git-репозиторию.
- Каталог данных берётся из `AGENTS_IMPROVEMENT_DATA_DIR`, затем из каталога данных установленного плагина; резервное место — `~/.cache/agents-improvement/<клиент>`. `AGENTS_IMPROVEMENT_CONFIG` позволяет указать отдельный пользовательский конфиг.
- Каждый новый чат получает снимок с SHA коммита, полными текстами и контрольными суммами. Идентификаторы чатов преобразуются в безопасные имена файлов. Снимок публикуется атомарно; при повторном запуске для того же чата побеждает уже сохранённая версия.
- Получение Git-данных идёт во временный отдельный репозиторий: параллельные чаты не меняют общую рабочую копию. Последняя успешная версия хранится отдельно для каждой комбинации источника, ветки и выбранных дополнений.
- При ошибке получения данных используется подходящий последний успешный снимок и показывается предупреждение. Если снимка нет, возвращается явная ошибка. Для старого чата без сохранённой версии загрузчик не подменяет условия свежими правилами, а предлагает открыть новый чат.
- Текст имеет строгий предел размера. В Codex отключается сокращение контекста именно для этого ограниченного по размеру хука, чтобы инструкции не заменялись превью.

## Проверки

1. Новый чат получает полный текст версии A; после изменения источника другой чат получает B.
2. Продолжение, повторный запуск процесса и сжатие первого чата сохраняют A, включая выбранные дополнения.
3. Недоступный источник даёт сохранённый текст с предупреждением; отсутствие кэша даёт явную ошибку.
4. Параллельные вызовы для одного чата возвращают одну закреплённую версию.
5. Некорректный конфиг, повреждённый снимок, симлинк вместо инструкции и превышение размера обнаруживаются явно.
6. JSON-манифесты, пути, конфигурации обоих клиентов и загрузка полного текста в Codex проверяются отдельно от тестов загрузчика.

Тестовые Git-истории создаются только как изолированные данные тестов и не меняют рабочую историю репозитория. После реализации пользователь отдельно поручил проверить русский язык документации и отправить первый релиз в `master`.

## Результаты и оставшаяся проверка

- Девять тестов загрузчика пройдены на Windows с Node.js 24.11.1 и Git 2.52.0. Включено сравнение полных утверждённых текстов для обоих адаптеров.
- `node scripts/check.mjs` проверяет манифесты, каталоги, пути и конфигурации хуков.
- `claude plugin validate` принимает плагин и каталог без предупреждений (Claude Code 2.1.126).
- Codex 0.171.0-alpha.13 зарегистрировал локальный каталог плагинов и установил `agent-instructions@agents-improvement` версии 0.1.0. Его `hooks/list` возвращает синхронный `sessionStart`, полный лимит контекста и отсутствие ошибок/предупреждений. Состояние доверия — `untrusted`.
- После пользовательского подтверждения Review hooks нужно проверить, что настоящий контекст Codex содержит полный текст и SHA. Это ещё не доказано одними тестами загрузчика и обнаружением хука.
- Установка по публичной ссылке проверяется при публикации версии 0.1.0; запуск в реальной сессии Claude отложен до проверки Codex.

Установка и настройки описаны в [документации плагина](../../plugins/agent-instructions/README.md). Исполняемый код и Markdown обновляются отдельно; локальная установка плагина не делает незакоммиченные правила доступными через удалённый источник.
