# agents-improvement

Личный набор дословных инструкций и скиллов для работы с агентами. Цель — один раз подключить общие требования и меньше повторять их в каждой задаче. Основной клиент — Codex; плагин также подготовлен для Claude Code.

- [Базовые инструкции](prompts/base.md) — утверждённый текст правил.
- [Дополнение Graphify](prompts/optional/graphify.md) — включается отдельно для выбранного проекта.
- [Инструкции агента](plugins/agent-instructions/README.md) — подключение, обновления, настройки и проверка плагина.
- [План развития](docs/plans/2026-11-21-agents-improvement-roadmap.md) — назначение, границы и ближайшие шаги.
- [Версия 0.1.0](docs/releases/0.1.0.md) — состав первого релиза, проверки и ограничения.

## Подключение

Установи плагин из ветки `master`:

```sh
codex plugin marketplace add https://github.com/s-yurchenko/agents-improvement.git --ref master
codex plugin add agent-instructions@agents-improvement
```

В Codex Desktop проверь хук через **Review hooks** или **Settings → Hooks**, затем открой новый чат. Нужны Node.js 20.11+ и Git в PATH приложения. Подробности и команды для Claude — в [инструкции плагина](plugins/agent-instructions/README.md).

Новый чат получает опубликованную версию правил. Продолжение чата использует сохранённый снимок. Изменения в рабочей папке ещё не являются обновлением для подключённых клиентов.

## Разработка

Внешних зависимостей нет:

```sh
npm run check
npm test
```

Тесты создают временные локальные Git-репозитории, проверяют обновления и сохранность текста. Они не обращаются к удалённому источнику и не меняют историю рабочего репозитория.

Версия 0.1.0: плагин реализован и установлен локально в Codex, тесты загрузчика и валидация Claude пройдены. Полная проверка запуска в Codex ожидает подтверждения доверия к хуку. Claude в реальной сессии пока не проверялся.
